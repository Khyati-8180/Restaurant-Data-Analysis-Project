# 🍽️ Restaurant Data Analysis Project

## 📌 Overview
This project analyzes restaurant data to extract insights about:
- Cost trends
- Ratings
- Cuisine classification
- Area-based analysis

---

## 🛠️ Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn

---

## 📊 Tasks Performed

### 🔹 Task 1: Data Cleaning
- Removed unnecessary columns
- Handled missing values
- Cleaned column names

### 🔹 Task 2: Cost Analysis
- Calculated average cost per area
- Visualized top 10 expensive locations

### 🔹 Task 3: Cuisine Classification
- Built Decision Tree model
- Predicted cuisine category
- Evaluated using accuracy score

### 🔹 Task 4: Rating Prediction
- Used Random Forest Regressor
- Predicted restaurant ratings
- Evaluated using MSE and R² score

---

## 📈 Output
- Bar Graph: Top 10 Expensive Areas
- Scatter Plot: Cost vs Rating
- ML Model Results

---
